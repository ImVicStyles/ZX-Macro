# ZX-Macro

Macro con interfaz y modos configurables para Fortnite.

## Iniciar

```bash
python main.py
```

## Modos incluidos

- Drag Edit
- Prefire Macro
- Pullout Shotgun

## Configuración

Los ajustes se guardan en `config.json`, con delay configurable (0ms por defecto) y
hotkeys por modo desde la UI.
